# Uttam Cybersecurity Portfolio

## Production commands

Install dependencies once:

```bash
npm install
```

Create the optimized production site in `dist/`:

```bash
npm run build
```

Preview that production build locally:

```bash
npm run preview
```

For hosting environments that require a start command:

```bash
npm run start
```

## Deploying

This is a static React/Vite site. Set the build command to `npm run build` and publish directory to `dist` on Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any static host.
